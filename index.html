📍 ウェイポイントの追加・編集

  • 地図をクリック/タップ → ウェイポイントを追加
  • マーカーをクリック → 名称・種別・滞在時間などを編集
  • スマホ：マーカーを長押し（約0.7秒）→ 編集画面を開く（削除ボタンあり）
  • サイドバーのリストをドラッグ → 順番を変更（コースラインも連動）

↔ 経路調整点の使い方

  • 「↔ 調整点」モードで地図をクリック → 経路調整点を追加
  • 調整点がある区間は直線で引かれます（OSRM自動ルートより優先）
  • 農道・山道など細い道の上に調整点を密に置いてください
  • PC：調整点を右クリック → 削除
  • スマホ：調整点を長押し（約0.7秒）→ 削除
  • 「● 調整点表示」ボタンで表示/非表示を切替（ルートは保持）

🔴 ルート線の編集

  • 赤い破線をドラッグ → そこに調整点が追加されルートが変形
  • 調整点がない区間 → OSRMが道路に沿って自動ルーティング
  • 調整点がある区間 → 調整点を直線でつないだルート（手動優先）
  • 調整点を非表示中はルート線のドラッグは無効になります

💾 保存・読み込み

  • 「💾」ボタン → ブラウザに保存（GitHub Pages）またはメモリ保存
  • 「📥」ボタン → JSONファイルでダウンロード（どこでも復元可能）
  • 一覧画面の「📂 JSONから読み込む」→ JSONファイルを読み込み

📷 マップを画像で保存

  • 「📷」ボタン → 現在の地図表示をPNG画像でダウンロード
  • GitHub Pages上で動作します（プレビュー環境では地図タイルが白になる場合があります）

⏱ 所要時間の計算

  • 歩行速度4km/h × 距離 + 各ウェイポイントの滞在時間の合計
  • 滞在時間はウェイポイント編集画面で分単位で設定できます
